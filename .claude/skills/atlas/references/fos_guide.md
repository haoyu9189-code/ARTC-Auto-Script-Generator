# Phase 0 三题指南(FoS / SEA 来源 / 置信度)

> 三题同构:都问 + 带依据选项 + 系统可推荐。FoS 与置信度是**独立维度**:
> FoS = 物理裕量(改及格线),置信度 = 预测可信度(改修正严苛度),
> 可自由组合,绝不互替。(HANDOFF §6)

## Q1 安全系数 FoS(问用户)

| 场景 | FoS 区间 | 犹豫时取 |
|------|---------|---------|
| 人身安全相关 | 1.5–2.0 | 2.0 |
| 设备防护 | 1.3–1.5 | 1.5 |
| 一般工业 | 1.15–1.3 | 1.3 |

来源:通用机械设计安全系数惯例(工程手册级共识,source_type=vendor/惯例)。

## Q2 SEA 设计值来源(问 + 收集后推测)

a) 给能量 + 最大力 → `scripts/sea_backcalc.py` 反推(SEA_required = E/(ρ̄·V·ρs);σ_plateau ≤ F_max/A);缺体积**必须追问几何包络**,不得默认
b) 直接给 SEA → `scripts/sea_sanity.py` 核验合理性(PA12 带 0.3–8 kJ/kg)
c) 只知用途 → **不甩区间,主动追问**:落高/速度/对象质量/最大允许减速度(g)/可用空间/单次或复用,然后按 a) 反推
d) demo → 用示例值并显式标注

## Q3 置信度等级(问 + 按 Q1 联动推荐)

| 等级 | 误差容忍 | 行为 |
|------|---------|------|
| 筛选级 | ±30% | 解析筛 + DB 检索即可 |
| 设计参考级 | ±15–20% | 强制 Size-Effect 修正 + 工具证据齐备 |
| 接近定稿级 | 最严 | 强制 Size-Effect + 全 FEA 终审 + **必须实测提示** |

推荐联动:Q1 人身安全 → 定稿级;设备防护 → 参考级;一般工业 → 筛选级。

## 设计输入确认块(问询完必须回显)

```
SEA_design = SEA_required × FoS     ← 已含 FoS
σ_plateau_max = F_max / A           (若适用)
置信度等级 = …(修正严苛度,与 FoS 独立)
```

**红线:margin = pred/design ≥ 1.0 即 PASS,此后任何环节不得二次乘 FoS。**
报告推荐表必须有 SEA/刚度裕度列(margin = pred/design)。
