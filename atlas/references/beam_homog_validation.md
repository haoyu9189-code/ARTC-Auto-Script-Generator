# beam_homog 金标准验证报告(P2-1b)

**协议**:目录列出的 Ex/Ey/Ez 经 pcu 条目反推确认在 **ρ̄=1%** 取值
(Ex=3.34e-3=0.33×0.01,与 E_z=ρ̄/3 解析解一致)。抽样 = 立方条目
(a=b=c=1, 90°)每 40 取 1,排除 * 标记;装饰条目经 seeds.py 同款
商图规范化;半径由一阶密度反解 r=√(ρV/πΣL)(1% 处一阶式精确);
beam_homog 以 Es=1、ν=0.3 归一运行。

**结果(n=24)**:

| 统计 | 值 |
|------|-----|
| 中位 max|dev| | **0.9%** |
| p90 | 15.1% |
| 最大 | 20.0%(tet_Z05.0_E11865) |
| >30% 待归因 | 0 条 |
| 解析失败 | 0 条 |

**偏差 >10% 条目归因**(5/24,全部为正偏):
mon_Z07.1_E3123(+13.0%)、tet_Z03.7_E10640(+16.0%)、
cub_Z04.0_E11108(+16.3%)、tet_Z05.0_E11865(+20.0%)。
共性:均为含软弯曲方向的低对称网(tet/mon 命名=母网晶系较低),
其最软轴模量绝对值小,对节点建模差异敏感;偏差全部为正与
刚接 Timoshenko(节点转动连续)相对目录均质化框架略硬一致。
该量级(≤20%)落在 Tier-B screening 误差带设计范围内。

**结论**:beam_homog 在细长杆区(梁理论适用域)与 ETH 独立均质化
数据一致性良好,可作 Tier-B 裁判;高密度区(自家库 l/d≈4–7)
误差由 P2-1c 用自家 FEA DB 标定节点刚化修正后另行给出误差条。
