## 2. 指标提取(NT-2,ISO 13314 + Li 2006)

- 致密化 ε_d = 能量吸收效率 η(ε)=W/σ 的全局峰(限 ε>0.1);
- **comp_EA 积分严格截到 δ_d=ε_d·H0**(修掉积满全曲线导致 SEA 虚高的主坑);
- 平台应力 σ_pl = 20–40% 应变均值(或截到 ε_d);
- **SEA = comp_EA ÷ 实心杆质量**(m=ρ_material·V0·ρ̄,非包络质量);
- 载荷轴 Y:H0=CELL·ny、A0=CELL²·nx·nz(n>1 轴向约定已修正)。

## 3. 硬有效性门(NT-3)+ margin 接线(NT-4)

五硬门全过才 `margin_eligible`(abaqus_fea):① ALLKE/ALLIE≤5%(准静态)
② ALLAE/ALLIE≤5%(沙漏)③ 接触耗散(ALLVD+ALLFD)/ALLIE≤10% ④ 致密化已达

### 7b-update:n=3 半速复核 → 撤回单 run 的"设计级"声称(2026-06-11)

补做 n=3 半速(sr=2 vs sr=4)不变性检验,结果**不在容差内**:

| ε_d 判据 | SEA(sr=4)| SEA(sr=2)| 差异 |
|---|---|---|---|
| 效率法 argmax | 4.72 | 3.52 kJ/kg | **25.4%** ✗ |
| 1.3·σ_pl 平台末端 | 3.06 | 3.74 kJ/kg | 22% ✗ |

**根因(已确诊,非 bug)**:同一应变截断时曲线几乎一致——comp_EA@ε=0.55 两速
**仅差 2.0%**(150.8 vs 147.9 mJ)、平台应力 σ_pl 仅差 **2.5%**(0.638 vs 0.622 MPa)。
25% 全部来自**致密化起点 ε_d 检测不稳**:该多胞柱压溃曲线的致密化是渐进/双峰的,
效率法 argmax 与 1.3·σ_pl 都在 0.45–0.70 间跳(加重平滑无效,见实验)。

**结论(诚实)**:① **平台应力(2.5%)与到固定应变的能量(2%)是 rate-stable 的**;
② **"积分到致密化"的 SEA 对 ε_d 检测过敏 → 单 run 不够稳,本次半速差 25%** →
**撤回前述单 run 的"设计级 margin 3.14"声称**,该值降为 screening。
③ 真实物理(曲线、平台)是稳的;不稳的是 SEA 的"到致密化"定义在本拓扑上的可判定性。

**待用户定夺的协议选择**(详见汇报):致密化模糊时,用 (a) **到固定参考应变的 SEA**
(如 ε=0.5,rate-stable 2%,落带 ~3.2 kJ/kg,可授设计级,但口径=到目标行程非到致密化);
或 (b) 多 run 平均 + 误差带的"到致密化"SEA;或 (c) 改用**平台应力**为吸能 margin 量
(最稳)。三者都正当,口径不同。

### 7c:完整 (3,3,3) 块 → 去横向 X/Z 残余边界(2026-06-18)

精化 (1,3,1)(纵向 n=3、横向仍 n=1):跑**全 (3,3,3)= 27 胞块**,横向也 n=3。

| 量 | (1,3,1) 纵 n3·横 n1 | **(3,3,3) 全 n3** | 变化 |
|---|---|---|---|
| 平台应力 σ_pl | 0.633 | **0.901 MPa** | +42% |
| SEA(ε=0.5,主 margin)| 2.89 | **3.96 kJ/kg** | **+37%** |
| SEA 合理带 | ✓ | **✓ 带内** | — |
| KE p90 / mean | 0.029 / 0.013 | **0.020 / 0.009** | 准静态 ✓ |
| 接触耗散 | 0.066 | 0.087 | <0.10 ✓ |

**物理**:横向加邻胞约束后柱子不能自由外张 → 屈曲阻力↑ → 平台/SEA↑。即 (1,3,1) 的
**横向自由面在低估** SEA(↓37%)。(3,3,3) 是标准代表性块,值更可信。

**诚实边界(关键)**:(1,3,1)→(3,3,3) 跳 37% 说明**横向尚未渐近收敛**——(3,3,3)
仍只有 1/27 胞是全内部,外层仍是边界胞。真渐近值需**周期 BC 的 RVE 或更大 n**(预期
再略升)。故 **3.96 kJ/kg 是当前最佳代表性估计、非渐近终值**。速率稳定性:参考应变
SEA 口径已在 (1,3,1) 半速证 0.8%(metric 性质,此处继承);(3,3,3) 半速复核为可选
(9× 算力)。**中期跟进**:周期 BC RVE / n=5 收敛研究求渐近 SEA。
