## Caveats

- All three sim sessions use **60% compression** (CLAUDE.md's note about NS2 using 80% is outdated; verified via preprocess.py).
- NS3 has many variant runs (sphere×1.2 production, mesh sweeps, sliderN, testA-H Truncated_cube probes); kept all, distinguished by `variant` column.
- Cross-session duplicates of the same (topology, N) are kept; use `session` column to filter.
- Experiment topology names (`Isotruss`, `Octettruss`) renamed in `topology` column to canonical (`Iso_truss`, `Octet_truss`); `topology_raw` preserves original.
- Only `feature_data.txt` and `density_temp.txt` (sim) plus `.csv`/`.xtak` (exp) are copied; large `.odb`/`.inp`/`.dat` files stay in source dirs.
