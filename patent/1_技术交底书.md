## 三、背景技术

### 3.1 技术背景

晶格结构（Lattice Structure）是增材制造技术中的重要应用方向，具有轻量化、高比强度、可定制吸能特性等优势，广泛应用于航空航天、汽车碰撞吸能、生物医学植入物等领域。

晶格结构的力学性能受多个参数影响：
- **拓扑类型**：BCC、FCC、Diamond、Kelvin等（20+种典型结构）
- **几何参数**：晶胞尺寸（Cell Size）、杆件半径（Strut Radius）
- **拓扑变换参数**：Slider（控制结构渐变）
- **加载方式**：静态/动态、压缩/剪切

### 3.2 现有技术的问题

| 问题类别 | 具体描述 |
|----------|----------|
| **建模效率低** | 每种参数组合需手动建模，一个完整参数空间（24结构×5尺寸×6半径×9slider）= 6480组合，人工操作需数月 |
| **仿真管理困难** | 批量仿真缺乏统一调度，无法自动跳过已完成任务，集群资源利用率低 |
| **接触面配置繁琐** | 不同晶胞结构几何差异大，接触面识别需硬编码mask，每新增结构需重新调试 |
| **数据格式不统一** | 各仿真输出格式各异，难以进行跨结构、跨参数的对比分析 |
| **缺乏智能应用** | 数据库建成后仅能人工查表，无法进行快速检索和反向设计 |

#### 5.1.2 动态接触面检测方法

**技术问题**：不同晶胞结构几何差异大，如何自动识别与刚性板的接触面？

**技术方案**：

```python
def detect_contact_faces(part, cell_size, tolerance=0.01):
    """
    动态接触面检测算法

    输入：part - 晶胞几何体
          cell_size - 晶胞尺寸
          tolerance - 容差（默认0.01mm）

    输出：top_faces, bottom_faces - 顶部和底部接触面集合
    """
    target_z_top = cell_size / 2
    target_z_bottom = -cell_size / 2

    top_faces = []
    bottom_faces = []

    for face in part.faces:
        vertices = face.getVertices()
        face_center = face.getCentroid()
        face_normal = face.getNormal()

        # 多重检测策略
        # 策略1：顶点Z坐标检测
        vertex_match_top = any(abs(v.z - target_z_top) < tolerance for v in vertices)
        vertex_match_bottom = any(abs(v.z - target_z_bottom) < tolerance for v in vertices)

        # 策略2：面中心Z坐标检测
        center_match_top = abs(face_center.z - target_z_top) < tolerance
        center_match_bottom = abs(face_center.z - target_z_bottom) < tolerance

        # 策略3：法向量验证（顶面法向量应朝上或水平）
        normal_valid_top = face_normal.z >= -0.1
        normal_valid_bottom = face_normal.z <= 0.1

        # 综合判定
        if (vertex_match_top or center_match_top) and normal_valid_top:
            top_faces.append(face)
        if (vertex_match_bottom or center_match_bottom) and normal_valid_bottom:
            bottom_faces.append(face)

    # 兜底策略：若未找到，选择Z坐标最接近的面
    if not top_faces:
        top_faces = find_closest_faces(part, target_z_top)
    if not bottom_faces:
        bottom_faces = find_closest_faces(part, target_z_bottom)

    return top_faces, bottom_faces
```

**技术效果**：
- 消除硬编码mask配置，支持24种晶胞结构零配置集成
- 自适应处理复杂几何（如Kelvin、Weaire-Phelan等多面体结构）

```python
def standardize_curve(displacement, force, target_points=50):
    """
    力-位移曲线标准化插值

    静态分析：插值到50点
    动态分析：插值到500点
    """
    # 1. 位移收敛检测（删除收敛后的冗余数据）
    convergence_idx = detect_convergence(displacement)
    displacement = displacement[:convergence_idx]
    force = force[:convergence_idx]

    # 2. 均匀插值
    x_uniform = np.linspace(displacement.min(), displacement.max(), target_points)
    f_interp = interp1d(displacement, force, kind='linear', fill_value='extrapolate')
    y_uniform = f_interp(x_uniform)

    return x_uniform, y_uniform
```

#### 5.2.1 单特征检索方法

**技术问题**：给定目标性能值，如何快速检索最接近的材料？

**技术方案**：

```python
def search_single_feature(database, feature_name, target_value, top_k=3):
    """
    单特征检索算法

    输入：database - 特征数据库（820+样本）
          feature_name - 特征名称（density/stiffness/SEA等）
          target_value - 目标值
          top_k - 返回前K个最接近的材料

    输出：Top-K材料列表，按距离排序
    """
    # 1. 特征归一化（消除量纲影响）
    feature_values = database[feature_name]
    feature_min = feature_values.min()
    feature_max = feature_values.max()
    feature_range = feature_max - feature_min

    # 2. 计算归一化距离
    normalized_distances = abs(feature_values - target_value) / feature_range

    # 3. 排序返回Top-K
    top_k_indices = normalized_distances.argsort()[:top_k]

    return database.iloc[top_k_indices]
```

```python
def search_dual_features(database, feature1, target1, feature2, target2):
    """
    双特征多目标优化算法

    核心思路：
    1. 构建两个特征的响应曲面
    2. 提取目标值对应的等值线
    3. 计算两条等值线的交点
    4. 交点即为同时满足两个目标的最优解
    """
    # 1. 提取参数空间
    radii = database['radius'].unique()
    sliders = database['slider'].unique()

    # 2. 构建响应曲面（网格插值）
    grid_r, grid_s = np.meshgrid(
        np.linspace(radii.min(), radii.max(), 100),
        np.linspace(sliders.min(), sliders.max(), 100)
    )

    surface1 = griddata(
        points=(database['radius'], database['slider']),
        values=database[feature1],
        xi=(grid_r, grid_s),
        method='cubic'
    )

    surface2 = griddata(
        points=(database['radius'], database['slider']),
        values=database[feature2],
        xi=(grid_r, grid_s),
        method='cubic'
    )

    # 3. 提取等值线
    contour1 = extract_contour(grid_r, grid_s, surface1, target1)
    contour2 = extract_contour(grid_r, grid_s, surface2, target2)

    # 4. 计算交点
    intersections = find_contour_intersections(contour1, contour2)

    return intersections  # [(radius, slider), ...]
```

#### 5.2.3 压实点自动检测方法

**技术问题**：如何自动识别应力-应变曲线的密实化拐点？

**技术方案**：

```python
def detect_densification_point(strain, stress, yield_stress=None):
    """
    压实点检测算法

    原理：密实化点是应力-应变曲线从平台区进入密实区的拐点，
          对应二阶导数d²σ/dε²首次显著增大的位置。

    算法步骤：
    1. 在strain > 0.35范围内搜索（跳过弹性区和平台初期）
    2. 限制stress < 2×yield_stress（避免应力暴涨区干扰）
    3. 计算二阶导数
    4. 找d²σ/dε²首次超过阈值的点
    """
    # 1. 均匀重采样（消除采样不均影响）
    strain_uniform = np.linspace(strain.min(), strain.max(), 100)
    stress_uniform = interp1d(strain, stress, kind='cubic')(strain_uniform)

    # 2. 平滑滤波（抑制噪声）
    stress_smooth = uniform_filter1d(stress_uniform, size=5)

    # 3. 计算导数
    d_strain = strain_uniform[1] - strain_uniform[0]
    d1 = np.gradient(stress_smooth, d_strain)  # 一阶导数
    d2 = np.gradient(d1, d_strain)              # 二阶导数

    # 4. 搜索范围限定
    search_mask = strain_uniform > 0.35
    if yield_stress:
        search_mask &= stress_smooth < 2 * yield_stress

    # 5. 阈值检测
    d2_search = d2[search_mask]
    threshold = np.max(d2_search) * 0.3  # 自适应阈值

    above_threshold = np.where(d2_search >= threshold)[0]
    if len(above_threshold) > 0:
        densification_idx = np.where(search_mask)[0][above_threshold[0]]
        return strain_uniform[densification_idx]

    # 6. 兜底策略
    if yield_stress:
        idx = np.argmin(np.abs(stress_smooth - 1.5 * yield_stress))
        return strain_uniform[idx]

    return strain_uniform[-1] * 0.7  # 默认返回70%应变
```

## 八、权利要求书（草案）

### 独立权利要求

**权利要求1**：一种增材制造晶格结构力学性能数据库的快速构建方法，其特征在于，包括以下步骤：

S1：定义参数空间，包括晶胞类型、几何参数和分析类型；

S2：自动遍历参数空间，针对每组参数组合，基于预设模板生成有限元仿真脚本，所述脚本包括预处理脚本、求解器输入文件和后处理脚本；

S3：采用三阶段分离执行流程执行仿真：
- 第一阶段：执行预处理脚本生成求解器输入文件后退出；
- 第二阶段：调用求解器进行并行计算；
- 第三阶段：执行后处理脚本提取力-位移数据；

S4：对提取的力-位移数据进行标准化插值处理，输出统一格式的数据库文件。

**权利要求2**：根据权利要求1所述的方法，其特征在于，所述S2中生成仿真脚本时，采用动态接触面检测方法识别晶胞结构与刚性板的接触面，包括：
- 基于目标Z坐标进行顶点匹配检测；
- 基于目标Z坐标进行面中心匹配检测；
- 基于法向量方向进行面朝向验证；
- 当上述检测均未匹配时，采用最近面兜底策略。

**权利要求3**：根据权利要求1所述的方法，其特征在于，所述S3中执行仿真前，进行智能断点续算判定，判定条件包括：
- 结果文件存在且大小超过预设阈值；
- 提取的最大位移值超过目标位移阈值；
满足上述条件时跳过该仿真任务。

**权利要求4**：一种基于权利要求1-3任一所述方法构建的数据库的智能应用方法，其特征在于，包括：

单特征检索：基于归一化距离计算，返回与目标值最接近的Top-K材料；

双特征优化：构建两个特征的响应曲面，提取目标值对应的等值线，计算等值线交点作为多目标优化解。

**权利要求5**：根据权利要求4所述的方法，其特征在于，还包括压实点自动检测方法：
- 对应力-应变曲线进行均匀重采样和平滑滤波；
- 计算二阶导数d²σ/dε²；
- 在应变大于0.35的范围内，检测二阶导数首次超过自适应阈值的位置作为压实点。

**权利要求6**：一种实现权利要求1-5任一所述方法的系统，其特征在于，包括：
- 脚本生成模块：用于参数空间遍历和仿真脚本批量生成；
- 批处理执行模块：用于三阶段分离执行和断点续算管理；
- 数据标准化模块：用于力-位移曲线插值和数据库输出；
- 智能应用模块：用于特征检索、多目标优化和可视化分析。

## 九、实施例

### 实施例1：BCC晶格结构数据库构建

**参数配置**：
- 晶胞类型：BCC
- 晶胞尺寸：4, 5, 6 mm
- 杆件半径：0.3, 0.35, 0.4, 0.45, 0.5 mm
- Slider：0-8
- 分析类型：StaCompre, DynaCompre_500

**执行过程**：
1. 系统自动生成 3×5×9×2 = 270 组仿真脚本
2. 批处理脚本执行三阶段流程
3. 智能跳过已完成的任务
4. 输出标准化JSON数据库

**结果**：
- 有效样本数：268（2个因几何退化失败）
- 数据库大小：2.3 MB
- 构建时间：72小时（集群8节点并行）

### 实施例2：材料反向设计

**需求**：寻找同时满足 density≈0.25 和 stiffness≈500 MPa 的晶格结构

**操作**：
1. 在智能应用界面选择双特征搜索
2. 输入 Feature1=density, Target1=0.25
3. 输入 Feature2=stiffness, Target2=500
4. 系统显示等值线交点分析

**结果**：
- 推荐参数：BCC, radius=0.42, slider=3
- 预测性能：density=0.248, stiffness=512 MPa
- 误差：<3%
