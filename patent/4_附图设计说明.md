## 图4：动态接触面检测原理图

### 设计要求
- **类型**：三维示意图+算法流程
- **尺寸**：A4横向
- **风格**：左侧3D示意图，右侧算法流程

### 布局设计

```
┌─────────────────────────────────┐  ┌─────────────────────────────────────┐

│                                 │  │                                     │
│     Z = +cell_size/2            │  │  输入: 晶胞几何体, cell_size        │
│     ─────────────────  ← 顶面   │  │            │                        │
│           ╱╲                    │  │            ▼                        │
│          ╱  ╲                   │  │  ┌─────────────────────────┐       │
│         ╱    ╲                  │  │  │计算目标Z坐标            │       │
│        ╱  ○   ╲    ← 晶胞结构  │  │  │Ztop = +cell_size/2     │       │
│       ╱   │    ╲               │  │  │Zbottom = -cell_size/2  │       │
│      ╱────┼────╲               │  │  └──────────┬──────────────┘       │
│     ╱     │     ╲              │  │             │                       │
│    ╱      ○      ╲             │  │             ▼                       │
│   ╱───────────────╲            │  │  ┌─────────────────────────┐       │

│     Z = -cell_size/2           │  │  └──────────┬──────────────┘       │
│                                 │  │             │                       │
│     ↑                          │  │             ▼                       │
│     │ 法向量                   │  │  ┌───────────────────────────────┐ │
│     │ 朝上                     │  │  │ 检测1: 顶点Z坐标              │ │
│                                 │  │  │ any(|v.z - Ztarget| < ε) ?   │ │
│                                 │  │  └──────────┬────────────────────┘ │
│   检测条件:                     │  │             │                       │
│   ① 顶点Z ≈ target_z           │  │             ▼                       │
│   ② 面中心Z ≈ target_z         │  │  ┌───────────────────────────────┐ │

│                                 │  │             ▼                       │
│                                 │  │  ┌───────────────────────────────┐ │
│                                 │  │  │ 检测3: 法向量验证             │ │
│                                 │  │  │ 顶面: normal.z ≥ -0.1        │ │
│                                 │  │  │ 底面: normal.z ≤ +0.1        │ │
│                                 │  │  └──────────┬────────────────────┘ │
│                                 │  │             │                       │
│                                 │  │             ▼                       │
│                                 │  │  ┌───────────────────────────────┐ │

│                                 │  │                                     │
```
